A day with your agent

You kick off a task and get up from your desk. Here's what your watch shows you next.

  1. It asks for permission

    The agent wants to run a command. Allow it, deny it with or without a reason, or pick “always” so you're never bothered about it again. A countdown tells you how long it will wait for you.

  2. It hesitates, you decide

    A multiple-choice question arrives with its options: tick one or several, or dictate another answer. A plan to review? Approve it or ask for changes.

  3. You know who's working

    Your active sessions at a glance: working, waiting for your answer, done. The ones waiting on you come first.

  4. It celebrates your wins

    Task done: Chi throws a party and earns experience. As it levels up, it unlocks new accessories. You can reply with the keyboard, by voice or with a quick reply.

  5. And it gets hungry

    Fullness, energy, happiness: its gauges drop over time. Feed it, play with it, give it a cuddle. It panics when your agent needs you.

    And what goes in must come out: every now and then, it poops next to itself. From two on, it sulks. One tap on Clean and it's all tidy, even while it sleeps.

  6. Your streaks count

    Days in a row with finished tasks, answers given from the watch: achievements unlock as your sessions go by.

  7. It respects your nights

    Quiet hours, Do not disturb and the watch's Bedtime mode: notifications go quiet. Non-urgent events are bundled into a single summary, and only urgent ones get through.

Your server, your data

Agentchi goes through a small open-source relay server. The one at agentchi.dev is already set up: the watch and the plugins connect to it out of the box, nothing to install or host. And if you'd rather stay in control, you can always host your own.

Your watch
  • Nothing piles up. Events go straight to the right watch without being kept; the server only stores registered watches and their codes.

  • No account, no ads. Each watch registers itself and only receives its own events.

Install Agentchi

This server relays Claude Code and Codex hooks to your watch, and lets you answer from it. The commands below already include its address.

Server address {{.URL}}

  1. The app on your watch

    Agentchi will install from the Google Play Store, right on your Wear OS watch.

    Get it onGoogle Play Coming soon

    Open Agentchi, allow notifications, then go to Settings › Server: enter {{.URL}} and tap Connect the watch.

  2. One code per computer

    On the watch: Settings › Server › New code. Write down the XXXX-XXXX-XXXX code. Plan one code per computer or cloud environment: each one can be revoked separately.

  3. Hook up your agents

    Claude Code (terminal, IDE, Desktop app, Remote Control)

    A single command, with your code:

    claude plugin install agentchi --marketplace Pelagoss/agentchi \
  --config server_url={{.URL}} --config code=XXXX-XXXX-XXXX

    The code is stored in the system keychain, not in settings.json. Without --config, Claude Code prompts for both values (/plugin › agentchi › Configure options). Requires curl, available by default on macOS, Linux and Windows 10+.

    Claude cloud sessions (claude.ai/code)

    Cloud sessions don't load plugins. Add this block to the repo's .claude/settings.json (download), then, in your cloud environment settings:

    • environment variable AGENTCHI_CODE=<your code>;
    • custom network access allowing {{.URL}}.

    Everyone working on the repo uses their own code: without a code, the hook does nothing.

    {{.Cloud}}

    Codex (CLI, app, IDE; macOS, Linux, WSL)

    Register the Codex hooks (download) and make your code visible to Codex:

    curl -fsS {{.URL}}/v1/codex-hooks.json -o ~/.codex/hooks.json
echo 'export AGENTCHI_CODE=XXXX-XXXX-XXXX' >> ~/.zshrc   # or ~/.bashrc

    If you already have a ~/.codex/hooks.json, merge the two instead of overwriting it. Codex ignores a hook until you've approved it: run /hooks in Codex and approve Agentchi's. With Codex, the watch receives task completions and permission requests, and can answer them; multiple-choice questions stay on the computer (Codex doesn't pass them to hooks).

  4. Check, then step away

    Settings › Server › Test push: the server sends a notification and the watch shows the error if it doesn't go through. Then turn on Settings › Replies › Reply from the watch when you leave your screen.
