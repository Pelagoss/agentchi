Une journée avec ton agent

Tu lances une tâche et tu te lèves. Voilà ce que ta montre te montre ensuite.

  1. Il te demande la permission

    L'agent veut lancer une commande. Autorise, refuse avec ou sans explication, ou choisis « toujours » pour ne plus être dérangé pour ça. Un compte à rebours te dit combien de temps il t'attend.

  2. Il hésite, tu choisis

    Une question à choix arrive avec ses options : coche-en une ou plusieurs, ou dicte une autre réponse. Un plan à valider ? Approuve-le ou demande des changements.

  3. Tu sais qui travaille

    Les sessions en cours, d'un coup d'œil : au travail, en attente de ta réponse, terminées. Celles qui t'attendent passent en premier.

  4. Il fête tes victoires

    Tâche terminée : Chi fait la fête et gagne de l'expérience. En montant de niveau, il débloque de nouveaux accessoires. Tu peux répondre au clavier, à la voix ou d'une réponse rapide.

  5. Et il a faim

    Satiété, énergie, bonheur : ses jauges baissent avec le temps. Nourris-le, joue avec lui, fais-lui un câlin. Il s'affole quand ton agent a besoin de toi.

    Et ce qui rentre finit par sortir : de temps en temps, il fait caca à côté de lui. À partir de deux, il boude. Un toucher sur Nettoyer et tout est propre, même pendant qu'il dort.

  6. Tes séries comptent

    Jours d'affilée avec des tâches terminées, réponses données depuis la montre : les succès se débloquent au fil des sessions.

  7. Il respecte tes nuits

    Heures calmes, Ne pas déranger et mode Coucher de la montre : les notifications se font discrètes. Les événements non urgents se regroupent en un seul résumé, et seules les urgences passent.

Ton serveur, tes données

Agentchi passe par un petit serveur relais open source. Celui d'agentchi.dev est déjà configuré : la montre et les plugins s'y connectent d'emblée, rien à installer ni à héberger. Et si tu préfères garder la main, tu peux toujours héberger le tien.

Ta montre
  • Rien ne s'accumule. Les événements filent aussitôt vers la bonne montre, sans être conservés ; le serveur ne garde que les montres enregistrées et leurs codes.
  • Un code par ordinateur. Chaque ordinateur ou environnement cloud a le sien, révocable depuis la montre.
  • Pas de compte, pas de publicité. Chaque montre s'enregistre toute seule et ne reçoit que ses événements.

Installer Agentchi

Ce serveur relaie les hooks de Claude Code et de Codex vers ta montre, et lui permet d'y répondre. Les commandes ci-dessous contiennent déjà son adresse.

Adresse du serveur {{.URL}}

  1. L'appli sur ta montre

    Agentchi s'installera depuis le Google Play Store, directement sur ta montre Wear OS.

    Disponible surGoogle Play Bientôt

    Ouvre Agentchi, accepte les notifications, puis Paramètres › Serveur : saisis {{.URL}} et touche Connecter la montre.

  2. Un code par ordinateur

    Sur la montre : Paramètres › Serveur › Nouveau code. Note le code XXXX-XXXX-XXXX. Prévois un code par ordinateur ou par environnement cloud : chacun se révoque séparément.

  3. Branche tes agents

    Claude Code (terminal, IDE, appli Desktop, Remote Control)

    Une seule commande, avec ton code :

    claude plugin install agentchi --marketplace Pelagoss/agentchi \
  --config server_url={{.URL}} --config code=XXXX-XXXX-XXXX

    Le code est rangé dans le trousseau du système, pas dans settings.json. Sans --config, Claude Code demande les deux valeurs (/plugin › agentchi › Configure options). Il faut curl, présent par défaut sur macOS, Linux et Windows 10+.

    Sessions cloud Claude (claude.ai/code)

    Les sessions cloud ne chargent pas les plugins. Ajoute ce bloc au .claude/settings.json du dépôt (télécharger), puis, dans les paramètres de ton environnement cloud :

    • variable d'environnement AGENTCHI_CODE=<ton code> ;
    • accès réseau personnalisé autorisant {{.URL}}.

    Chaque personne qui travaille sur le dépôt met son propre code : sans code, le hook ne fait rien.

    {{.Cloud}}

    Codex (CLI, appli, IDE ; macOS, Linux, WSL)

    Enregistre les hooks Codex (télécharger) et rends ton code visible de Codex :

    curl -fsS {{.URL}}/v1/codex-hooks.json -o ~/.codex/hooks.json
echo 'export AGENTCHI_CODE=XXXX-XXXX-XXXX' >> ~/.zshrc   # ou ~/.bashrc

    Si tu as déjà un ~/.codex/hooks.json, fusionne les deux plutôt que de l'écraser. Codex ignore un hook tant que tu ne l'as pas approuvé : lance /hooks dans Codex et approuve ceux d'Agentchi. Avec Codex, la montre reçoit les fins de tâche et les demandes d'autorisation, et peut y répondre ; les questions à choix restent sur l'ordinateur (Codex ne les passe pas aux hooks).

  4. Vérifie, puis éloigne-toi

    Paramètres › Serveur › Tester le push : le serveur envoie une notification et la montre affiche l'erreur si elle ne part pas. Puis active Paramètres › Réponses › Répondre depuis la montre quand tu quittes ton écran.
