Host your own Agentchi server

By default, the watch and the plugins go through agentchi.dev, already set up and free to use. If you'd rather keep everything under your control, the relay server is open source and runs anywhere.

What the server does

It receives the events your Claude Code and Codex hooks send, and pushes each one right away to the right watch through Firebase Cloud Messaging. It doesn't keep events: it only stores registered watches and a hash of their codes. A question waiting for your answer lives in its memory for five minutes at most. It's multi-user: each watch registers itself and only receives its own events.

It's a single Go binary with no dependencies, which also serves the home page and these guides with its own address in every command.

What you need

  • A Firebase project (free) with an Android app for the package fr.codingpacer.agentchi, and a service account key so the server can send pushes.
  • A watch build tied to that project: push tokens belong to a Firebase project, so the watch app has to be built with your project's values. The repository's CI produces that APK, which installs with adb.
  • A domain name pointing at your server, with ports 80 and 443 open.

Docker Compose

Caddy obtains the HTTPS certificate on its own. Put your service account key in server/firebase-service-account.json, then:

git clone https://github.com/Pelagoss/agentchi && cd agentchi/server
chmod 644 firebase-service-account.json    # readable by the container
CC_DOMAIN=agentchi.example.com docker compose up -d

Without Docker

Run go build in server/ and start the binary behind your reverse proxy. Let POST /ask requests stay open for five minutes: Traefik and Caddy do so by default.

VariableRole
CC_FCM_CREDENTIALSPath to the service account key, required for pushes
CC_ADDRListen address, :8080 by default
CC_DATAState file, data/state.json by default
CC_PUBLIC_URLPublic address shown in the commands, otherwise taken from the request
CC_TRUST_PROXYtrue behind a reverse proxy
CC_MAX_DEVICESMaximum number of watches, 1000 by default, 0 for no limit
CC_INDEXABLELets search engines index the site. Leave it unset: your instance stays reachable but out of search results

Connect the watch and your agents

On the watch, Settings › Server: enter your server's address and tap Connect the watch. Then open your server's home page: it gives the plugin command, the cloud session block and the Codex hooks with its address. Finish with Settings › Server › Test push, which shows the error on the watch if a push doesn't go through.
