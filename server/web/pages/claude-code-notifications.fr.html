Les notifications Claude Code sur ta montre

Claude Code s'arrête et attend dès qu'il lui faut une autorisation, qu'il a une question ou qu'il a fini une tâche. Agentchi envoie chacun de ces moments sur ta montre Wear OS et te laisse y répondre, pour qu'une longue tâche ne reste pas bloquée pendant que tu es loin du clavier.

Pourquoi des notifications pour Claude Code

Tu confies à Claude Code une tâche de vingt minutes, puis tu vas te faire un café. Au bout de deux minutes, il veut lancer npm test et attend ton feu vert. À ton retour, la tâche n'a pas avancé.

La cloche du terminal et les notifications du bureau ne servent que si tu es devant ton ordinateur. Agentchi passe par les hooks de Claude Code pour envoyer chaque événement sur ta montre, où que tu sois, et renvoie ta réponse à la session.

Répondre depuis la montre est un réglage : active Paramètres › Réponses › Répondre depuis la montre quand tu quittes ton écran. La montre attend ta réponse jusqu'à cinq minutes ; au-delà, la question reste sur l'ordinateur, comme sans Agentchi.

L'installer en trois étapes

  1. Installe l'appli sur ta montre, ouvre-la, puis Paramètres › Serveur › Connecter la montre.
  2. Crée un code : Paramètres › Serveur › Nouveau code te donne un code XXXX-XXXX-XXXX. Prévois-en un par ordinateur, chacun se révoque depuis la montre.
  3. Installe le plugin sur ton ordinateur :
claude plugin install agentchi --marketplace Pelagoss/agentchi \
  --config server_url={{.URL}} --config code=XXXX-XXXX-XXXX

Le code est rangé dans le trousseau du système, pas dans settings.json. Le plugin a besoin de curl, fourni avec macOS, Linux et Windows 10 et plus récents. Vérifie ensuite le tout avec Paramètres › Serveur › Tester le push.

Terminal, IDE, Desktop, Remote Control et cloud

Le plugin marche partout où Claude Code tourne sur ton ordinateur : dans le terminal, dans VS Code ou JetBrains, dans l'appli Desktop, et dans les sessions Remote Control que tu suis depuis claude.ai/code ou l'appli mobile Claude, puisqu'elles tournent toujours sur ta machine.

Les sessions cloud de claude.ai/code ne chargent pas les plugins. Pour elles, ajoute un hook http au .claude/settings.json du dépôt (télécharger le bloc), définis AGENTCHI_CODE dans les variables de l'environnement cloud et autorise {{.Host}} dans son accès réseau. Le guide d'installation donne le bloc prêt à copier.

Des notifications qui respectent tes nuits

Heures calmes, Ne pas déranger et mode Coucher de la montre la rendent silencieuse. Les événements non urgents sont regroupés en un seul résumé ; seuls passent ceux où ton agent est bloqué. Pour chaque type d'événement, tu choisis plein écran, notification normale ou discrète, motif de vibration et son.

Et une mascotte qui vit avec tes sessions

Chi, un compagnon pixel-art, fête chaque tâche terminée, gagne de l'expérience et débloque des accessoires. Il a aussi faim, et panique quand ton agent a besoin de toi. Ses jauges et tes séries donnent une raison douce de jeter un œil, pas une alerte de plus.
