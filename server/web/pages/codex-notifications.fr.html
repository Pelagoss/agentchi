Les notifications Codex sur ta montre

Codex peut travailler seul un bon moment, jusqu'à ce qu'il lui faille ton accord pour lancer une commande ou qu'il arrive au bout de sa tâche. Agentchi envoie ces moments sur ta montre Wear OS grâce aux hooks de Codex, et lui renvoie ta réponse : plus besoin de surveiller le terminal.

Ce qui arrive sur ta montre

Dans CodexSur la montreCe que tu peux faire
Demande d'autorisation : commande, modification de fichier, outil MCPCe que Codex veut faire, avec un compte à reboursAutoriser ou refuser, avec ou sans raison
Tâche terminéeLa fin du dernier message de l'agent, et Chi fait la fêteRépondre au clavier, à la voix ou par une réponse rapide
Sessions qui démarrent et se terminentL'écran Sessions en coursVoir quelles sessions tournent

Répondre depuis la montre est un réglage : active Paramètres › Réponses › Répondre depuis la montre quand tu quittes ton écran. La montre attend ta réponse jusqu'à cinq minutes ; au-delà, la demande reste sur l'ordinateur.

L'installer

Sur la montre, connecte-toi au serveur et crée un code (Paramètres › Serveur › Nouveau code), un par ordinateur. Puis, sur ton ordinateur, enregistre les hooks et rends le code visible de Codex :

curl -fsS {{.URL}}/v1/codex-hooks.json -o ~/.codex/hooks.json
echo 'export AGENTCHI_CODE=XXXX-XXXX-XXXX' >> ~/.zshrc   # ou ~/.bashrc
  • Tu as déjà un ~/.codex/hooks.json ? Fusionne les deux fichiers au lieu d'écraser le tien (voir les hooks d'Agentchi).
  • Approuve les hooks. Codex ignore un hook tant que tu ne l'as pas approuvé : lance /hooks dans Codex et approuve ceux d'Agentchi.
  • Tu préfères un plugin ? Dans l'appli Codex de bureau, ajoute la marketplace avec codex plugin marketplace add Pelagoss/agentchi, puis installe agentchi-codex depuis le répertoire des plugins. Il lit le code dans AGENTCHI_CODE et le serveur dans AGENTCHI_SERVER.

Termine par Paramètres › Serveur › Tester le push sur la montre : si quelque chose cloche, la montre affiche l'erreur.

Où ça marche

Le CLI Codex, l'appli Codex et l'extension IDE, sur macOS, Linux et Windows via WSL : tous exécutent les mêmes hooks de ~/.codex/hooks.json.

Limites actuelles

  • Les questions à choix multiples de Codex restent sur l'ordinateur : Codex ne les transmet pas aux hooks.
  • Dans Sessions en cours, une session Codex ne repasse pas « au travail » quand tu lui écris, car ses hooks ne signalent pas les messages envoyés.

Tu utilises aussi Claude Code ? La même montre et le même serveur gèrent les deux : voir les notifications Claude Code.
