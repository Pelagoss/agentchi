Claude Code notifications on your watch

Claude Code stops and waits whenever it needs a permission, has a question or finishes a task. Agentchi sends each of those moments to your Wear OS watch and lets you answer from there, so a long task doesn't sit idle while you're away from your keyboard.

Why Claude Code needs notifications

You hand Claude Code a task that takes twenty minutes, then get up to make coffee. Two minutes in, it wants to run npm test and waits for your OK. When you come back, the task hasn't moved.

The terminal bell and desktop notifications only help when you're at your computer. Agentchi uses Claude Code hooks to forward each event to your watch, wherever you are, and sends your answer back to the session.

What lands on your watch

Question with optionsThe question and its optionsTick one or several, or dictate another answer
Plan to reviewThe plan, Markdown includedApprove it or ask for changes

Task failedThe error, as a notificationRead it at a glance
Subagent finished, context compactedOptional notifications, off by defaultTurn them on in the settings
Sessions starting and endingThe Active sessions screenSee who's working, who's waiting for you, who's done

Answering from the watch is a setting: turn on Settings › Replies › Reply from the watch when you leave your screen. The watch waits up to five minutes for your answer; after that, the question stays on the computer, just as it would without Agentchi.

Set it up in three steps

  1. Install the app on your watch, open it, then Settings › Server › Connect the watch.
  2. Create a code: Settings › Server › New code gives you an XXXX-XXXX-XXXX code. Use one per computer, each can be revoked from the watch.
  3. Install the plugin on your computer:
claude plugin install agentchi --marketplace Pelagoss/agentchi \
  --config server_url={{.URL}} --config code=XXXX-XXXX-XXXX

The code is stored in the system keychain, not in settings.json. The plugin needs curl, which ships with macOS, Linux and Windows 10 and later. Then check it all with Settings › Server › Test push.

Terminal, IDE, Desktop, Remote Control and the cloud

The plugin works wherever Claude Code runs on your computer: in the terminal, in VS Code or JetBrains, in the Desktop app, and in Remote Control sessions you follow from claude.ai/code or the Claude mobile app, since those still run on your machine.

Cloud sessions on claude.ai/code don't load plugins. For those, add an http hook to the repo's .claude/settings.json (download the block), set AGENTCHI_CODE in the cloud environment's variables, and allow {{.Host}} in its network access. The install guide has the block ready to copy.

Notifications that respect your nights

Quiet hours, Do not disturb and the watch's Bedtime mode silence the watch. Non-urgent events are bundled into a single summary; only the ones where your agent is blocked get through. For each kind of event, you choose full screen, a regular or silent notification, the vibration pattern and the sound.

And a mascot that lives with your sessions

Chi, a pixel-art companion, celebrates each finished task, earns experience and unlocks accessories. It also gets hungry, and panics when your agent needs you. Its gauges and your streaks are a gentle reason to check in, not one more alert.
